# C13 implementation status

C13 is implemented but remains unverified pending physical-device testing.

Automated coverage includes pregame player and spectator recovery, initiator and non-initiator
restart migration, restart-to-pregame with a server-migrated subset of original players,
unsupported attendance/recovery/bootstrap rejection, Clue Starved clue thresholds and display,
and the existing Quick Rematch lifecycle.

No C13 capability should be marked DONE in the feature matrix until the physical test pass is
recorded here.
